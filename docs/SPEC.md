# 블링 가계부 — 기능 명세서

## 1. 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 블링 가계부 (Bling Budget) |
| 사용자 수 | 1명 (개인용) |
| 플랫폼 | PWA (모바일 우선, 데스크톱 반응형) |
| 호스팅 | Vercel |
| 프론트엔드 | Next.js 14 (App Router) + TypeScript + Tailwind CSS |
| 백엔드 / DB | Supabase (PostgreSQL + Auth + RLS) |
| 인증 | Supabase Auth (이메일/매직링크) |
| 언어 | 한국어 (KO) |
| 통화 | KRW (원), 한국식 만/억 표기 |

## 2. 화면 구조

```
/                  → 홈 (대시보드)
/transactions      → 내역
/add               → 거래 입력 (모달 또는 풀스크린)
/budget            → 예산 관리
/settings          → 설정 메인
/settings/categories
/settings/accounts
/settings/budget
/settings/recurring
/login             → 로그인 / 매직링크
```

모든 화면 하단에 5탭 네비게이션: 홈 · 내역 · ＋입력 · 예산 · 설정

## 3. 화면별 핵심 기능

### 3.1 홈 (`/`)

위에서 아래 순서로:

1. 상단 — 인사말 + 알림 벨
2. 월 네비게이션 — 이전/다음 달
3. **현재 총 자산** (탭하면 자세히)
   - 순자산 큰 숫자
   - 현금·예금 / 저축·연금 / 대출 3분할
4. **이번달 현황** 헤더
5. 이번달 잔액 카드 — 잔액 / 수입 / 지출
6. 카테고리별 — 도넛 + Top 5, 지출/수입 탭
7. 지출수단별 — 신용/체크/페이/현금 진행률
8. 2026년 총 흐름 — 월별 막대 차트
   - **탭 가능**: 다른 월 탭 시 위쪽 "이번달 현황" 섹션 전체가 그 달로 갱신

### 3.2 거래 입력 (`/add`)

위에서 아래 순서로:

1. 상단 — 닫기(✕) + 제목 + 단계 표시 (2/4 등)
2. 진행 바 — 4단계 시각화
3. 종류 토글 — 수입 / 지출 / 이동
4. 금액 입력 — 큰 숫자 + 한국식 보조 표기 (예: "13,000 / 1만 3,000원")
5. **단계 아코디언** — 위에서 차례로 잠금 해제
   - ① 대분류 선택 (카테고리)
   - ② 소분류 선택 (위에서 고른 대분류의 자식만 표시)
   - ③ 결제수단 선택
   - ④ 메모 (선택사항)
6. 하단 — "저장" 버튼 (또는 단계별 "다음")

### 3.3 내역 (`/transactions`)

1. 기간 토글 — 월별 / 3개월 / 연간
2. 기간 합계 카드 — 합계 / 수입 / 지출
3. 날짜별 그룹 리스트
   - 날짜 헤더 (5월 11일 (월) · 하루 합계)
   - 거래 카드 — 카테고리 아이콘 + 이름 + 소분류·고정 표시 + 금액 + 결제수단

거래 탭 시 → 입력 화면에 데이터 채워서 편집 모드

### 3.4 예산 (`/budget`)

1. 큰 카드 — 남은 예산 / 진행률 바 / 하루 평균 가능액
2. 알림 카드 — 80% 이상 카테고리 안내
3. 카테고리별 진행률 리스트
   - 색상 단계: 0~79% 청록, 80~94% 주황, 95%+ 코랄

### 3.5 설정 (`/settings`)

1. 프로필 카드 — 이름 / 이메일 / 편집
2. **가계부 설정** 그룹
   - 카테고리 관리
   - 결제수단 · 계좌
   - 월별 예산 설정
   - 고정비 관리
3. **앱 설정** 그룹
   - 예산 초과 알림 (ON/OFF)
   - 월 시작일 (기본 1일)
   - 화면 테마 (자동/라이트/다크)
4. **데이터** 그룹
   - CSV 내보내기
   - 구글 시트 동기화 (V2 검토)
   - 로그아웃

## 5. 금액 표기 규칙

| 범위 | 표기 |
|---|---|
| `< 10,000원` | 그대로 콤마 (예: `3,900원`) |
| `10,000 ~ 9,999,999원` | `X만` 또는 `X만 X천원` (예: `62만 8천원`) |
| `10,000,000 ~ 99,999,999원` | `X,XXX만원` (예: `9,600만원`) |
| `≥ 100,000,000원` | `X억 Y만원` (예: `3억 1,052만원`) |
| 입력 중 | 정확한 숫자 표시 + 한국식 보조 표기 병기 |

## 6. 사용자 흐름 (Critical Path)

```
[앱 열기]
   ↓
[홈] → 오늘 자산/이번달 한 눈에 확인
   ↓
[＋ 입력 탭]
   ↓
[1] 종류·금액
[2] 대분류 → 소분류 자동 표시
[3] 결제수단
[4] 메모 (선택)
   ↓
[저장] → 토스트 알림 → 홈으로 자동 복귀
```

평균 입력 시간 목표: **8초 이내**, 평균 3~4 탭.

## 7. 알림 정책

- 예산 진행률 80% 도달 시: 앱 내 배너
- 예산 진행률 100% 초과 시: 앱 내 경고 + 브라우저 푸시(허용 시)
- 고정비 누락 알림: 매월 정기 결제일에 등록 안 됐으면 알림

## 8. PWA 사양

- manifest.json (이름, 아이콘, 시작 URL, 테마 컬러)
- 서비스 워커 (오프라인 캐싱: 정적 자원만)
- 홈 화면 추가 안내 (iOS 안내 모달)
- 아이콘: 512, 192, 180 px

## 9. 인증·보안

- Supabase Auth 이메일/매직링크
- Row Level Security: 모든 테이블에 `auth.uid() = user_id` 정책
- Supabase 환경변수: NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY (클라이언트)
- 서버사이드 변경 시 service role 키는 절대 클라이언트 노출 금지
